## Обо мне

Делаю 1С, обмены и сервисы вокруг учёта. Сначала разбираю, где данные уже живут и где их переписывают руками, потом называю состав работ.

Пишу на Python и TypeScript: парсеры каталогов, Telegram-боты, небольшие веб-сервисы и локальные инструменты. Если учёт уже в 1С, сервис читает его оттуда.
