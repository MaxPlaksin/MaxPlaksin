## Обо мне

Там, где заказы, оплаты и остатки разъехались по разным местам, я собираю их обратно в один контур. 1С, обмены и сервисы вокруг учёта: сначала вскрываю, где данные уже живут и где их до сих пор переписывают руками, потом оставляю состав работ, который можно сдать и проверить.

Дальше это код. Python и TypeScript держат парсеры каталогов, Telegram-боты, кабинеты и локальные инструменты. Учёт остаётся в 1С. Сервис не заводит вторую память в таблицах: он приходит к первой.

Нейросети тоже остаются на своей машине. Генерация картинок крутится локально и рассчитана на 8 ГБ памяти: кадр не уходит на чужой сервер, модель работает рядом с учётом и файлами.
